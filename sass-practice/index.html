Quy trình Sass CLI

Sass biên dịch mã SCSS thành CSS chuẩn để trình duyệt sử dụng.

  1. 1Kiểm tra Node.js và npm bằng node -v và npm -v.
  2. 2Cài dependency của dự án bằng npm install.
  3. 3Biên dịch các tệp một lần bằng npm run build.
  4. 4Tự động biên dịch khi SCSS thay đổi bằng npm run watch.

✓ Các tệp CSS trong thư mục css/ được tạo từ SCSS.
