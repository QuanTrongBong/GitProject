# GitProject

Dự án thực hành các thao tác Git cơ bản: tạo repository, clone, commit và push mã nguồn lên GitHub.

## Cấu trúc

- `README.md`: giới thiệu dự án.
- `source/index.html`: trang chào mừng.
- `source/news.html`: trang tin tức mẫu.
- `halong_bay.html`: bài thực hành các thẻ HTML cơ bản với nội dung về Vịnh Hạ Long.
- `text_formatting.html`: bài thực hành định dạng văn bản HTML và CSS nội tuyến.
- `html_lists.html`: bài thực hành danh sách có thứ tự, không thứ tự và lồng nhau.
- `sass-practice/`: bài thực hành biên dịch SCSS sang CSS bằng Sass CLI.
- `sass-conversion/`: bài chuyển CSS truyền thống sang SCSS theo cấu trúc partial chuẩn.
- `sass-mixins/`: bài thực hành dùng Sass variables và mixins để tái sử dụng kiểu nút, thẻ và typography.
- `responsive-grid-sass/`: bài tái cấu trúc CSS responsive grid sang SCSS, dùng variables, mixins và partials.
- `template-page-sass/`: trang Template HTML/CSS được tái cấu trúc thành SCSS với variables, mixins, nesting và partials.
- `website-template-advanced/`: website template responsive dùng Sass, có hero, menu cố định, card dịch vụ và footer.
